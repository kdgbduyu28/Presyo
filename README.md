# Presyo

Palengke, pump and household prices near you, from Philippine government monitoring:

| Prices | Source | Detail | Updated |
|---|---|---|---|
| Rice, meat & eggs, seafood, vegetables, fruits, pantry (Metro Manila) | DA Bantay Presyo | per wet market + NCR average | daily |
| Same categories (rest of the country) | PSA OpenSTAT | province / big city / region | monthly |
| Gasoline, diesel, kerosene | DOE retail pump prices | city/town × brand | weekly |
| Fuel price adjustments | DOE prior notices | per oil company | weekly |
| LPG (11 kg) | DOE LPG monitoring | city/town × brand | monthly |
| Electricity | DOE (rates sheet) | per distribution utility | monthly |
| Meralco bill by kWh | Meralco residential bills table (PDF) | Meralco franchise | monthly |
| Grocery SRPs | DTI SRP bulletin | national | when DTI updates |
| Exchange rates | BSP Reference Exchange Rate Bulletin | 31 currencies + BSP USD buy/sell | daily (trading days) |
| Phones (iPhone, Galaxy) | Apple Store PH, Power Mac Center, Beyond the Box, iStore, Digital Walker websites | model × storage × store | checked twice a day; stored only when a price changes |
| Water | MWSS concessionaires (hand-maintained `data/static/water.json`) | Maynilad / Manila Water zones | quarterly |
| Jeepney & bus fares | LTFRB (hand-maintained `data/static/fares.json`) | national | when LTFRB changes fares |

No backend: a Python ingest turns the published PDFs/CSVs into normalized JSON,
and an Expo (React Native + web) app reads static files.

```
ingest/   Python (uv): fetch -> parse -> data/prices/<source>/*.json, then `build`
data/     normalized 2026+ history (committed), areas.json (PSGC + centroids), markets.json
app/      Expo app; reads app/public/data (generated by `presyo-ingest build`)
```

## Run

```bash
cd ingest && uv run presyo-ingest all     # fetch new reports + build app data
cd app && npm install && npx expo start --web
```

`./scripts/release.sh` builds and deploys to https://presyo.pages.dev (Cloudflare Pages).
`.github/workflows/update.yml` does the same twice a day; it needs a
`CLOUDFLARE_API_TOKEN` secret and a `CLOUDFLARE_ACCOUNT_ID` variable.

## Known gaps

- Water and fares are typed in by hand from MWSS-RO / LTFRB announcements: both sites
  sit behind a Cloudflare bot challenge. Update them each quarter (water FCDA) or when
  fares change, and bump `checked`.
- bsp.gov.ph rejects non-browser TLS clients; the forex source uses `curl_cffi` with a
  Chrome fingerprint.
- Gadget stores: the resellers run Shopify (open `/products.json`); Apple PH embeds prices in
  each iPhone page. A new `data/prices/gadgets_<store>/<date>.json` is written only when that
  store's prices or stock change; `data/gadgets-checked.json` holds the last check per store.

- North Luzon DOE fuel/LPG reports are scanned images: not parsed (needs OCR).
- DOE's new site only has fuel reports from late August 2026.
